# ТОТАЛЬНОЕ ТЗ: Новый лендинг Satva Samui — Йога-тур
## Переработка нового лендинга под структуру satvasamui.ru

**Версия:** 2.0 FINAL  
**Дата:** 23 апреля 2026  
**Файл:** `frontend/yoga.html` (новый файл, не трогаем `index.html`)  
**Стили:** `frontend/css/yoga.scss` → компилируется в `yoga.css`  
**Скрипты:** `frontend/js/yoga.js`

---

## 1. ОБЩАЯ КОНЦЕПЦИЯ

### Что делаем
Берём структуру и логику подачи старого сайта **satvasamui.ru** (Wix, йога-тур) и переносим её в новый технологический стек проекта (HTML/SCSS/JS). Дизайн — полностью новый, на основе дизайн-системы нового лендинга (`_variables.scss`). Тексты переписаны с нуля в современном стиле. Фото — скачаны со старого сайта.

### Чем это отличается от нового лендинга (`index.html`)
| Параметр | index.html (детокс) | yoga.html (йога-тур) |
|----------|--------------------|--------------------|
| Продукт | Детокс / Панчакарма | Йога-тур, всё включено |
| Структура | 8 секций, сложная | 14 секций, простая вертикаль |
| Навигация | Липкий хедер с меню | Минималистичный хедер, меню только на мобайле |
| CTA | «Получить консультацию» | «Оставить заявку на даты» |
| Акцент | Медицина, здоровье | Отдых, пляж, йога, атмосфера |

**CSS:**
```scss
.yoga-scroll-progress {
  position: fixed;
  top: 0; left: 0;
  height: 3px;
  width: 0%;
  background: $color-accent;
  z-index: 9999;
  transition: width 0.1s linear;

```

**JS:** обновляем `width` на каждый `scroll` event:
```js
const pct = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
document.getElementById('yogaScrollProgress').style.width = pct + '%';
```

```js
// Генерация превью: берём кадр на 1-й секунде через canvas
document.querySelectorAll('.yoga-reviews__card').forEach(card => {
  const video = card.querySelector('video');
  const canvas = document.createElement('canvas');
  video.addEventListener('loadedmetadata', () => {
    video.currentTime = 1;
  });
  video.addEventListener('seeked', () => {
    canvas.width  = video.videoWidth;
    canvas.height = video.videoHeight;
    canvas.getContext('2d').drawImage(video, 0, 0);
    video.poster = canvas.toDataURL('image/jpeg', 0.8);
    video.removeAttribute('src'); // освобождаем память
    video.load();
  });
  
  // Клик — открываем модалку
  card.addEventListener('click', () => {
    const src = card.dataset.video;
    const player = document.getElementById('yogaVideoPlayer');
    player.src = src;
    player.play();
    document.getElementById('yogaVideoModal').classList.add('is-open');
  });
});

// Закрытие
```

## 10. ФОРМА — ДЕТАЛЬНАЯ СПЕЦИФИКАЦИЯ

**Action:** `POST /api/contact`  
**Content-Type:** `application/x-www-form-urlencoded`

### Поля

| Поле | Тип | Обязательное | Правила |
|------|-----|:---:|---------|
| `name` | text | ✓ | мин. 2 символа, только буквы/пробел/дефис |
| `phone` | tel | ✓ | мин. 7 цифр, допустимы `+`, пробелы, дефисы, скобки |
| `preferred_date` | date | — | не обязательное |
| `booking_comment` | textarea | — | макс. 1000 символов |
| `consent` | checkbox | ✓ | должен быть checked |
| `cf-turnstile-response` | hidden | ✓ | заполняется Cloudflare Turnstile виджетом |
| `website` | text (honeypot) | — | должно быть пустым; если заполнено — JS блокирует отправку |

### Поведение формы (JS)

```
1. На submit:
   - Проверяем honeypot — если заполнен, тихо прерываем
   - Валидируем name, phone, consent
   - Блокируем кнопку submit: disabled + текст «Отправляем…»
   - POST fetch('/api/contact', { body: formData })
   - 200 OK → скрываем форму, показываем yogaFormSuccess
   - Ошибка    → показываем yogaFormError (с текстом про мессенджеры)
   - В любом случае разблокируем кнопку

2. Валидация в реальном времени:
   - На blur каждого поля — проверяем и добавляем класс .is-error / .is-valid
   - На input — убираем .is-error если стало валидным
```
