# QA Sprint 3b — йога-лендинг (форма, privacy, /yoga)

Отметьте вручную после проверки на `http://localhost:8765/yoga.html` и (после выкладки) на проде.

## Макет и регрессии

- [ ] Секция формы (14): фон `cta_sunset`, glass-панель, логотип, поля читаемы на 1440 / 768 / 375
- [ ] Модалка privacy: открытие по ссылке в чекбоксе, закрытие по ×, overlay, Esc
- [ ] Tab-цикл внутри модалки privacy не уходит за пределы диалога
- [ ] Полный скролл страницы: секции 00–14 без визуальных поломок

## Форма и API

- [ ] `GET /api/public-config` возвращает `turnstileSiteKey` (на localhost капча может не требоваться на бэкенде)
- [ ] Успешная отправка: `POST /api/booking` с `procedure: "Йога-тур на Самуи"`, в ответ 2xx → блок успеха, форма скрыта
- [ ] Ошибка сети / 4xx / 5xx → красный блок `#yogaFormError`, Turnstile сброшен

## Валидация и безопасность

- [ ] Консент снят → сообщение об ошибке, отправка не уходит
- [ ] Телефон короче 10 цифр → ошибка под полем / общая ошибка
- [ ] Honeypot: в DevTools заполнить `#yogaWebsite` → ожидается ошибка от API (400), заявка как у спама не должна пройти успешно
- [ ] Cooldown: две отправки подряд быстрее 5 с → предупреждение

## Доступность и motion

- [ ] `prefers-reduced-motion: reduce`: параллакс и pulse CTA отключены (как ранее)
- [ ] Консоль без ошибок JS, без 404 по `yoga.css`, `yoga.js`, картинкам, видео

## Lighthouse (desktop, при необходимости)

- [ ] Performance ≥ 85
- [ ] Accessibility ≥ 95
- [ ] SEO ≥ 95

## Прод (после деплоя)

- [ ] `https://satvasamui.site/yoga` открывается (rewrite на `yoga.html`)
- [ ] Тестовая заявка с прода, запись в БД / уведомление (по настройкам сервера)

---

**Примечание:** схема `POST /api/contact` с полями `preferred_date` / `booking_comment` для йога-лендинга **не используется**; заявки идут в `POST /api/booking` с полем `comment` (см. `BookingRequest`).
